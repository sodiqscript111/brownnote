# Brownnote

A small, buildless text editor. No installation or build step is required.

## Edit the code

- `dist/index.html`: page structure and controls.
- `dist/style.css`: colors, spacing, and responsive styles.
- `dist/app.js`: editing, word counts, fonts, spell-check toggle, and local draft storage.

Open `dist/index.html` in your browser to try your changes locally. Refresh the page after saving changes. Spell-check suggestions depend on your browser's spelling settings.

The hosted version is https://brownnote-editor.citrusmesa4.chatgpt.site/. Local edits do not automatically update the hosted version; ask Codex to publish them when ready.
